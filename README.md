# SPK-Prediksi-Risiko-Kematian-Neonatal
Sistem Pendukung Keputusan (SPK) berbasis Machine Learning yang dirancang untuk memprediksi risiko kematian neonatal (28 hari pertama) berdasarkan data klinis awal ibu dan bayi. Proyek ini diintegrasikan ke dalam antarmuka web interaktif menggunakan Streamlit untuk memberikan peringatan dini bagi tenaga medis
